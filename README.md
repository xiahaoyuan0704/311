# GIM Desktop（可解析真实 .gim、提取属性并渲染）

这版重点修复你反馈的问题：

- 打开后提示“二进制文件不支持渲染”
- 看不到任何属性

现在已支持：即便文件是二进制存储，也会自动尝试提取可识别属性（含中文编码）。

## 已实现能力

- 针对你现在的工作流，优先处理 **解压后的目录输入**（CBM/DEV/MOD/PHM）。
- 打开 `.gim`（zip）或解压目录。
- 非 zip 的 `.gim` 也可打开（单文件回退）。
- 多编码自动解码：`utf-8 / utf-8-sig / gb18030 / gbk / utf-16`。
- 属性解析不限 `.fam`：支持 `.fam/.cbm/.dev/.phm/.ini/.cfg/.txt/.gim`。
- 对“看起来是二进制”的文件，会尝试从字节中提取属性行（如 `[设计参数]`、`key=label=value`）。
- 对低可信度内容不再强行显示“属性表”，避免乱码刷屏；仅在提取到可信属性时展示。
- 若源文件经过加密/专有压缩且无公开格式，程序会提示为二进制占位，此时需要格式说明才能继续支持。
- 属性可视化编辑（键/显示名/值）并写回当前包。
- 渲染：
- `.mod` 渲染增强：支持 OBJ 网格、纯数字点云文本，以及二进制浮点点云自动渲染（不再直接提示“不是OBJ就回退”）。
- 选中 `.fam/.cbm/.dev/.phm` 时，会优先自动匹配同名 `.mod` 文件并渲染真实模型，而不是固定示意图。
  - 若同名未命中，会继续根据属性文本中的 `.mod` 路径/UUID 长 token 做关联匹配，尽量命中真实模型。
  - 若仍未命中，可点击工具栏“手动关联MOD”直接指定对应模型文件并立即渲染。
  - 支持渲染模式切换：`自动 / 3D线框 / 3D点云`，以三维效果优先。
  - 属性文件在缺少可用 `.mod` 时使用立体 3D 占位设备渲染（含基础光照与坐标轴指示）。
  - `.mod` 中 OBJ 文本支持 3D 实体面片渲染（含简易明暗）；
  - 确实无法解析时显示二进制占位预览。


## 乱码说明（这次修复）

之前出现乱码的主要原因是文件使用了非 UTF-8 编码或二进制封装。当前版本会：

- 自动尝试多编码解码，并按可读性评分选择最优结果；
- 对可疑二进制内容先做“属性行提取”，再进入属性解析；
- 只有达到最小可信条件（至少 1 条有效属性）才显示到属性表，避免把整屏随机二进制误当属性。

## 启动

```bash
./run_desktop.sh
```

或

```bash
python3 -m gim_desktop
```

## 测试

```bash
python3 -m unittest -v
python3 -m py_compile gim_desktop/*.py gim_editor.py gim_model.py launch_gim_editor.py
```

> 若在服务器/容器中无图形桌面（无 `$DISPLAY`），GUI 无法弹窗，这是环境限制。

- UI 文件树会优先显示这 4 个目录中的 `.fam/.cbm/.dev/.mod/.phm` 文件，避免噪声文件影响解析。
